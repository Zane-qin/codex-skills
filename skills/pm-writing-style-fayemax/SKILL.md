# pm-writing-style-fayemax

本 skill 固化飞书文档 [【FayeMax】文档写作 SOP & 业务 Background](<FEISHU_DOC_URL>) **Part 1** 的写作与排版规则，供所有 PM 类产出共用。

## 何时使用

- 用户明确要求按 FayeMax / Quokka / 该飞书 SOP 风格写或改文档。
- 用户正在使用 `pm-business-planning-doc`、`pm-prd-doc`、`pm-data-review-doc` 中任一 skill：**必须先按本 skill 执行文风与格式检查**（可只读 `references/part1-canonical.md` 快速对齐）。

## 执行步骤

1. 用 Read 工具打开 [`references/part1-canonical.md`](references/part1-canonical.md)，内化语言风格、表达习惯、排版表与常用句式。
2. 产出或修改正文时，逐项自检：结论是否在篇首或章首；假设是否单独列出并附理由；数据是否带口径与区间；优先级是否用 P0/P1/P2（或 P00）；并列信息是否尽量表格化。
3. 若用户给的是零散要点，先补「前置思考 / 写在前面」再展开细节。

## 与其他 skill 的关系

| Skill | 关系 |
|-------|------|
| `pm-business-planning-doc` | 结构模板 + **本 skill 文风** |
| `pm-prd-doc` | 结构模板 + **本 skill 文风** |
| `pm-data-review-doc` | 结构模板 + **本 skill 文风** |

**不要**在本 skill 中重复各类型文档的章节模板；章节结构以对应 `pm-*-doc` 为准，文风以本 skill 为准。
